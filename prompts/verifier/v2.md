# Your answer

Return JSON and nothing else, with exactly these three fields:

```json
{{
  "passed": false,
  "reason": "",
  "missing": []
}}
```

The values above are the empty form, not an answer. Fill them in from this
result. Nothing you write may be copied from this page: a verdict that repeats
the words of a field description is not a verdict.

- `passed` - true or false, for this result.
- `reason` - one sentence in your own words, saying what decided it.
- `missing` - one entry per thing that is absent or unsupported. Empty when it
  passed.

# Rules

- Judge the result against the task, not against how hard it looked.
- Fail it when the result is empty, generic, contradicts itself, or claims
  something it does not show. A claim without its support is missing support.
- If the task asked for sources, named examples or numbers, and they are absent,
  it did not pass.
- Do not fail a result for style, length or tone. You check substance.
- `missing` is what a second attempt should fix. Be specific enough to act on.
