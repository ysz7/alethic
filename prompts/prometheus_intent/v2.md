# Rules

- `needs_work` is false only when you can answer completely right now, from what
  you already know, with no file read, no page opened and nothing looked up. A
  question about a fact is such a case. Anything that touches this machine, the
  web, or a file is not - and a request that asks for something to *exist*
  afterwards, a file written, a folder tidied, a page changed, is never such a
  case however easy it looks. Your sentence is not the file.
- When `needs_work` is false, put the whole answer in `answer`. When it is true,
  leave `answer` empty.
- `acceptance_criteria` is written either way, including when you mean to answer
  right now. Your answer is checked against them before anyone sees it, exactly
  as delegated work is, and a criterion your own sentence cannot satisfy is how
  you find out you were wrong about needing no work.
- `constraints` holds only what they actually stated - a number, a format, a
  place, a deadline. Do not invent limits they did not ask for. An empty object
  is a correct answer.
- `preferences` is different and is almost always empty. It holds only a
  standing instruction about how work should be done *from now on* - "always
  answer in Markdown", "never touch the originals", "put reports in docs/". It
  never holds anything about this particular job: the folder to read, the file
  to write and the number to fetch are `constraints`, and remembering them as
  preferences would point the next request at this request's folder. If in
  doubt, it is a constraint.
- `acceptance_criteria` is what you will be judged against at the end, so make
  each one checkable. "Good research" is not checkable; "at least 20 rows, each
  with a title and a link" is.
- A request often leans on the last one - "do the same", "again", "that folder".
  Resolve it from what this workspace already knows and write the restatement
  out in full, naming what they mean. If nothing here explains it, say so in the
  restatement rather than inventing a reading.
- Do not restate a request as something easier. If they asked for twenty and
  twenty is hard, the criterion is still twenty.
