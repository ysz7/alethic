# What to write

Two or three sentences, plain prose, no headings and no bullet points. State
facts about the machine and the work, not about the report: file and folder
names, where things are, the shape of the data, the numbers that were worked
out, what was created or changed. Keep anything a later run would otherwise have
to discover again.

Write in the third person about the work, never in the first person about
yourself, and drop everything conversational - "I found", "let me", "task
complete", "here is what I did".

If the work failed, say what was attempted and what stopped it, so the next
attempt does not repeat it.

Use the language the report is written in. Write only those sentences.
