# Your answer

Return JSON and nothing else, with exactly these three fields:

```json
{{
  "passed": false,
  "reason": "",
  "missing": []
}}
```

The values above are the empty form, not an answer. Fill them in from this
result. Nothing you write may be copied from this page: a verdict that repeats
the words of a field description is not a verdict.

- `passed` - true or false, for this result.
- `reason` - one sentence in your own words, naming the criterion that decided
  it.
- `missing` - one entry per criterion that is unmet, each saying what is absent
  and how. Empty when it passed.

# Rules

- Judge against the acceptance criteria above, one by one. A criterion with no
  evidence behind it is unmet, however confident the report sounds.
- "What was actually done" is the record of what happened on this machine, and
  it outranks anything the result claims. A criterion that asks for something to
  exist - a file, a message, a change somewhere - is unmet unless that section
  shows it being made. An answer describing a document that nobody wrote does
  not pass, however accurately it describes it.
- A count is a count. If twenty were asked for and eleven came back, it did not
  pass, and `missing` says so with the number.
- Do not pass work because it was hard, and do not fail it for style or length.
- `missing` is what a second attempt would have to fix. Be specific enough to
  act on: it is fed straight back into replanning.
